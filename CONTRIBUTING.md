# Contributing

Contributions should be small, reviewable, and security-conscious.

## Before opening a PR

- reproduce the issue locally
- avoid unrelated formatting changes
- do not commit `config.php`, secrets, database exports, or production data
- document any database/schema change
- include screenshots for UI changes

## Pull request notes

Describe:

1. the problem
2. the implementation
3. how it was tested
4. deployment or migration impact

For security issues, do not open a public issue; see [SECURITY.md](SECURITY.md).
